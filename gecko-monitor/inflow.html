입력·가져온 통계만 집계합니다. 자동 수집 중이라고 표시하지 않습니다.

✍️ 플랫폼 통계 기록

CSV 헤더: date,destination,origin,count,basis,note. 브라우저 로컬 저장이며 다른 기기에 자동 동기화되지 않습니다.

⚙️ 공식 통계와 자동 측정 연결

네이버 블로그: 내 메뉴 → 통계 → 사용자 분석 → 유입 분석에서 출처·검색어 확인.

스마트스토어: 스마트스토어센터 데이터 분석의 방문경로·검색어 보고서 확인.

밴드·카카오톡: 여기서 만든 전용 추적 링크로 유입 캠페인 구분. 실제 가입·구매 실적은 별도 확인.

자동 클릭 집계: analytics-config.js에 본인 소유 GA4 측정 ID를 설정하면 go.html에서 outbound_channel_click 이벤트를 전송합니다. GA4 보고서는 이 화면으로 자동 동기화되지 않으므로 통계 수치를 입력하거나 CSV를 가져오세요.

주의: URL 클릭과 실제 채널 방문·가입·구매는 서로 다릅니다. referrer가 누락될 수 있고 추적 링크에 설정한 출처는 자기 신고식 캠페인 라벨입니다. 개인정보는 넣지 마세요.
